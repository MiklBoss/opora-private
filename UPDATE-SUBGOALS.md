# Опора: подцели и шаги — версия приложения 14

Обновление подготовлено из предоставленного архива текущей версии, коммит b2c824619e5ba9c8a5ef99894d5ab2d4801bfaab. Действующий сайт этим архивом не изменён.

## Использование

1. Откройте «Планы» или «Стратегию». Внутри карточки каждой цели появился блок «Подцели и шаги» → «Добавить».
2. Укажите название шага и, при необходимости, заметку. Можно добавлять любое число шагов, без обязательной даты.
3. Галочка рядом с шагом отмечает выполнение. Цель показывает число выполненных шагов и автоматический процент. Без шагов остаётся прежний ручной процент.
4. «На день» назначает шаг в план выбранной даты. Повторное назначение меняет дату того же задания, не создавая копию.
5. «Открыть день» переводит к заданию. Выполнение или редактирование в дне обновляет тот же шаг в цели.
6. Название шага можно нажать для редактирования. Удаление шага требует подтверждения и удаляет его связанное задание дня.

Шаги доступны также в кварталах и проектах. Это один уровень списка действий внутри цели; прежние связи между целями разных горизонтов сохранены.

## Прогресс и игра

- Процент считается по выполненным шагам, все шаги имеют равный вес. При 1 из 3 — 33%, при 2 из 3 — 67%.
- При наличии шагов ручной ползунок недоступен. Состав шагов и выполнение автоматически пересчитывают прогресс.
- Награда цели — общий фонд. Каждая отметка открывает соответствующую долю фонда; XP, обычные и золотые монеты округляются вниз, остаток достигается при завершении всех шагов.
- Назначенная на день задача шага не получает вторую самостоятельную награду.
- Первый полученный фонд фиксируется, как и в текущей игре. Снятие отметки, изменение или удаление шагов пересчитывает доступную награду согласно существующей логике отмены выполнения.
- Прежние самостоятельные задачи и цели без шагов используют прежние правила игры. Рутины, магазин, покупки и валюты сохранены.

## Сохранение

Шаги и связь с заданиями дня входят в экспорт/импорт и существующую синхронизацию GitHub. Прогресс вычисляется из записей шагов и заданий, поэтому после объединения изменений разных шагов на двух устройствах не зависит от последнего записанного процента цели.

Данные автоматически переводятся в формат 4 при использовании обновления. Форматы 1, 2 и 3 по-прежнему принимаются. Старые вкладки с приложением версии 13 не понимают формат 4 и покажут защитное предупреждение; на всех устройствах обновите приложение перед дальнейшей синхронизацией.

## Установка через Codex в существующий репозиторий

1. Скачайте резервную копию реальных планов в текущей Опоре. Синхронизируйте их с закрытым репозиторием данных.
2. Передайте этот архив в Codex внутри существующего проекта `opora-private`. Попросите применить обновление подцелей из архива, сначала сравнив исходники с текущим репозиторием, чтобы сохранить возможные более новые изменения.
3. Изменены: `app.js`, `core.js`, `game.js`, `styles.css`, `index.html`, `sw.js`. Добавлены `tests/goal-steps.test.mjs` и эта инструкция.
4. Не заменяйте `opora-data.json`, не очищайте browser storage и не удаляйте репозиторий данных. Файл данных намеренно отсутствует в пакетах обновления.
5. Выполните `npm test`. Затем проверьте внешний вид и сценарий на телефоне: цель → два шага → один выполнен → 50% → назначить на день → снять отметку в дне → прогресс обновился.
6. Опубликуйте существующим способом GitHub Pages, обновляя все шесть файлов вместе. Для ручной публикации готов `opora-github-pages.zip` внутри архива; его файлы кладутся в корень сайта.
7. Закройте старые вкладки на всех устройствах и откройте сайт снова. При необходимости используйте кнопку обновления приложения. Перед синхронизацией убедитесь, что блок «Подцели и шаги» появился.

## Проверки

Прошли 7 автоматических тестов модели: перенос старых данных, автоматический процент, общая отметка с дневной задачей, объединение офлайн-правок разных шагов, доли награды без удвоения, прежнее поведение самостоятельных целей, валидация и удаление шагов.

Дополнительно прошёл сценарий интерфейса в DOM: создать шаги в стратегии и планах → отметить → назначить/сменить дату → выполнить и отредактировать в дне → проверить общий фонд → перезагрузить → удалить шаг с подтверждением. Проверен синтаксис JavaScript.

Полноценная визуальная проверка в браузере не выполнена; перед публикацией проверьте мобильный внешний вид. Существующий механизм ручной синхронизации не изменялся.
