# Обновление скорости FamilyQuest

Это обновление не меняет правила, историю, балансы и таблицы.

## 1. Google Apps Script

Откройте существующий проект Apps Script. Замените содержимое файла
Adventure.gs содержимым одноименного файла из архива. Это файл скрипта,
НЕ Adventure.html. Code.gs менять не нужно.

Сохраните. Выберите «Развернуть» → «Управление развертываниями» → карандаш
у действующего веб-приложения → «Новая версия» → «Развернуть».
При обновлении существующего развертывания адрес /exec остается прежним.

## 2. GitHub

В репозитории nasch_kwest замените четыре файла в корне:

- adventure.js
- index.html
- game.css
- sw.js

config.js НЕ заменяйте: в нем остается ваш рабочий адрес Apps Script.
Дождитесь завершения публикации GitHub Pages, закройте и снова откройте игру.
Если старая версия осталась в установленном приложении, закройте все окна игры
и откройте снова. На компьютере можно обновить страницу Ctrl+Shift+R.

## Что изменилось

После входа с PIN галочка и предварительные очки появляются сразу.
Пока сервер отвечает, виден статус сохранения. Можно отмечать следующие
задания: игра отправляет их по очереди. Покупки и изменения героя доступны
после подтверждения сохранения, чтобы не тратить неподтвержденные монеты.

Сервер читает необходимые листы один раз за операцию и возвращает обновленное
состояние вместе с подтверждением. Второй полный запрос после записи больше
не нужен (при обновленном Adventure.gs).

При отказе сервера предварительное начисление отменяется. Если связь
оборвалась и результат неизвестен, появится «Повторити збереження».
Повтор использует тот же идентификатор, поэтому не начисляет награду дважды.
Очередь сохраняется при перезагрузке этой же вкладки. Не закрывайте вкладку,
пока есть неподтвержденные выполнения: это не постоянное офлайн-хранилище.

## Проверка

В автоматическом тесте с искусственной задержкой сервера 20 секунд интерфейс
отреагировал примерно за 5 мс. Проверены очередь, отказ сервера, потеря ответа,
повтор без двойного начисления и восстановление после перезагрузки вкладки.
Это тест локальной версии, а не измерение скорости Google Apps Script.
Само подтверждение Google по-прежнему зависит от его сервиса и интернета.

Проверьте после установки: отметьте реальное выполненное задание, дождитесь
статуса сохранения и обновите страницу. Галочка и очки должны остаться.
